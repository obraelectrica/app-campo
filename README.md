# App de campo – Obra Eléctrica

App Android para registrar avances y conexiones en obra, **incluso sin señal**.
Los registros se guardan en el celular y se suben solos cuando vuelve internet.

- Descargar la última versión: https://github.com/obraelectrica/app-campo/releases/latest/download/obra-electrica.apk
- Web de oficina: https://obraelectrica.github.io

## Cómo se actualiza
1. Reemplaza los archivos de `www/` (y sube el número de `version` en `package.json`).
2. GitHub construye la APK solo (pestaña **Actions**) y la publica en **Releases**.
